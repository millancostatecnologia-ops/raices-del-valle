# Raíces del Valle

Juego de granja y grietas para el navegador del móvil (uso personal).

Para jugar: activa GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root) y abre la URL que te dé GitHub. En el móvil, añádelo a la pantalla de inicio para jugar a pantalla completa.

Arte, música y sonidos: **Ninja Adventure**, de Pixel-boy y AAA (CC0) — pixel-boy.itch.io/ninja-adventure-asset-pack

Juega aquí: https://millancostatecnologia-ops.github.io/raices-del-valle/
